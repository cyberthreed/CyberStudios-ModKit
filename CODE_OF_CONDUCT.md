# ✦ CyberStudios Community Code of Conduct

CyberStudios is committed to maintaining a welcoming,
respectful environment for developers and creators.

## Our Expectations

Participants should:

- Treat others with respect.
- Offer constructive technical feedback.
- Respect differing experience levels.
- Credit other people's contributions.
- Discuss disagreements professionally.
- Respect project boundaries and licensing.

## Unacceptable Behavior

The following are not tolerated:

- Harassment or discriminatory abuse
- Threats or intimidation
- Doxxing or sharing private information
- Deliberate disruption of discussions
- Repeated personal attacks
- Malicious or intentionally harmful contributions

## Maintainer Responsibilities

Maintainers may moderate discussions, close issues,
reject pull requests, or restrict participation
when necessary.

Technical disagreement alone is not misconduct.

## Reporting

For ordinary moderation concerns, contact the
repository maintainers through an appropriate
GitHub channel.

Do not publish sensitive personal information
in public issues.

## Scope

This code applies to participation in official
CyberStudios ModKit repository spaces.

Thank you for helping make the community
collaborative and welcoming. ♡

## 🎀 a little peek behind the pixels

Throw a sleepover with custom event tasks, themed conversations, campfire spooky stories, and cozy buffs and emotions.

## ✧ inside the project

The [data patches](Content/JsonPatch) define the event and its interactions. [String tables](Content/String) and [textures](Content/Textures) hold the event text and artwork.

The [plugin descriptor](PajamaParty_F2D852DB.uplugin) and [project metadata](Meta) belong to the inZOI ModKit project. Use a compatible version of the official ModKit for development. For gameplay, use the official packaged download above.

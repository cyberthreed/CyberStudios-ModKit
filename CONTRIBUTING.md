# ✦ Contributing to CyberStudios ModKit

Thank you for your interest in contributing! ♡

CyberStudios ModKit is a source-available collection
of game modification projects.

We welcome bug reports, technical improvements,
documentation updates, and thoughtful contributions.

## Our Development Model

CyberStudios maintains final authority over:

- Project direction
- Code review and merging
- Official builds
- Release versions
- Nexus Mods and CurseForge uploads
- Distribution of official mod packages

Contributors may propose changes but cannot
independently publish official or unofficial builds
under the proposed ModKit source license.

## How to Contribute

1. Review existing issues and documentation.
2. Open an issue for substantial proposed changes.
3. Fork the repository.
4. Create a focused development branch.
5. Make and test your changes.
6. Submit a pull request to the main repository.
7. Wait for maintainer review and approval.

## Pull Request Requirements

Every pull request should include:

- A clear description of the change
- The affected mod or component
- Why the change is needed
- Testing performed
- Known limitations
- Relevant screenshots or logs, if applicable

Do not include unrelated changes.

## Code and Asset Guidelines

- Preserve existing project organization.
- Follow the conventions used by each mod.
- Avoid unnecessary dependency additions.
- Do not commit proprietary game assets.
- Do not include credentials or personal data.
- Clearly identify experimental behavior.
- Document compatibility assumptions.
- Respect third-party licenses.

## AI-Assisted Contributions

AI-assisted development is permitted.

All submitted work must still be reviewed for
correctness, licensing, security, and compatibility.

Contributors are responsible for the content of
their submissions.

## Redistribution

Contributing does not authorize reuploading,
redistributing, or independently publishing
covered mods under the proposed source license.

Official distribution is managed by CyberStudios.

## Contributor Rights

Contributors retain ownership of their original work
while granting the contribution permissions described
in the repository license.

Please review the license before submitting a PR.

## Questions

Thank you for helping improve the project. 💜
